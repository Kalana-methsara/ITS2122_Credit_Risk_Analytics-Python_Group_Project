# 📊 ITS 2122 - Credit Risk & Customer Financial Health Analytics

### 🏢 FinTrust Digital Finance - Capstone Project (Semester 3, 2026)
This repository contains the data science solutions, risk-monitoring framework, and strategic insights developed for **FinTrust Digital Finance** to identify credit card default risks and segment customers based on financial health.

---

## 📂 Project Structure
* `default of credit card clients.csv` - The raw historical dataset from UCI Machine Learning Repository.
* `Credit_Risk_Analytics.ipynb` - The primary Jupyter Notebook containing data cleaning, EDA, risk scoring, and API integration.
* `Strategic_Insights_Report.pdf` - The final executive board report.
