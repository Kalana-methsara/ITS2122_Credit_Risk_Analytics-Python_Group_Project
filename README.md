# Credit Risk Analysis Project

## Overview
This project analyzes customer credit risk using Python and machine learning techniques. The project is divided into five phases including data preprocessing, exploratory data analysis, customer segmentation, predictive modeling, and business recommendations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
